Amanu

Privacy

Amanu has no account and no hosted meeting library. Recordings and the files made from them live in the recordings folder on your Mac.

Meeting content

  • Recording, Parakeet transcription, the optional live transcript, and Ollama summaries run locally.
  • AssemblyAI or OpenAI transcription uploads meeting audio to the provider you choose.
  • Claude Code, Codex, Anthropic, and OpenAI summary or speaker-naming backends receive the transcript and available meeting context: title, call application, and calendar participants. Those tools may send it to their provider under your account’s terms.
  • API keys stay on the Mac and are sent only to the provider they authenticate.

Calendar access is optional. Calendar context stays local unless it is included in a request to a cloud or CLI model as described above.

Product analytics

Anonymous usage reporting is on by default and can be disabled in Setup, Settings → Setup, or with amanu analytics off. It never includes meeting content, names, paths, keys, or error text. See the complete event list, retention, and deletion instructions.

Website analytics

This site sends a first-party request to amanu.me/m for a page view, and an aggregate download_clicked event when a release link is clicked. Page views contain the page path and title, screen dimensions, and referrer when supplied; the download event contains its fixed name and current page path. The server also receives ordinary HTTP metadata such as IP address and user agent. The site sets no analytics identifier, does not connect website activity to the app installation ID, and loads no third-party analytics script.
