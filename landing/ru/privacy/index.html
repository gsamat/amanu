Конфиденциальность

У Amanu нет аккаунтов и облачной библиотеки встреч. Записи и созданные из них файлы лежат в папке на вашем маке.

Содержание встреч

  • Запись, расшифровка Parakeet, расшифровка на ходу и выжимки Ollama работают локально.
  • При выборе AssemblyAI или OpenAI звук встречи загружается выбранному провайдеру для расшифровки.
  • Claude Code, Codex, Anthropic и OpenAI для выжимок или имён говорящих получают расшифровку и доступный контекст: название встречи, приложение звонка и участников из календаря. Эти инструменты могут отправить данные своему провайдеру по условиям вашего аккаунта.
  • API-ключи остаются на маке и передаются только провайдеру, для которого предназначены.

Доступ к календарю необязателен. Контекст календаря остаётся локальным, кроме описанных выше запросов к облачной или CLI-модели.

Аналитика приложения

Анонимная статистика использования включена по умолчанию. Её можно отключить при первой настройке, в Настройках → Первая настройка или командой amanu analytics off. Содержание встреч, имена, пути, ключи и тексты ошибок не отправляются. Полный список событий, срок хранения и удаление данных.

Аналитика сайта

При просмотре страницы сайт отправляет запрос на собственный адрес amanu.me/m, а при нажатии на ссылку релиза — агрегированное событие download_clicked. Просмотр содержит путь и заголовок страницы, размер экрана и источник перехода, если браузер его передал; событие скачивания — только фиксированное имя и путь текущей страницы. Сервер также получает обычные данные HTTP-запроса, например IP-адрес и user agent. Сайт не задаёт аналитический идентификатор, не связывает посещение с идентификатором установки приложения и не загружает сторонних счётчиков.
