# Лендинг Amanu

Самодостаточный двуязычный статический сайт: английская версия в `index.html`,
русская в `ru/index.html`, общий `style.css` и ассеты в `assets/` — без сборки,
внешних ресурсов и сторонних скриптов.

Маршруты: `/` — английский по умолчанию, `/ru/` — русский. На корне nginx
проверяет `Accept-Language`: если `ru` есть в списке языков браузера, посетитель
получает временный редирект на `/ru/`; иначе корень остаётся английским. Ручной
переключатель между версиями расположен в футере. Для локального просмотра нужен
любой статический сервер, чтобы абсолютные ссылки работали так же, как в бою.

Проверки: `python3 tests/check.py` — маршруты, языковые метаданные и переключатель,
локальность всех ресурсов, честность Windows-блока, доступность, обе темы,
reduced-motion.

Боевой адрес: `https://amanu.me`. Статику отдаёт nginx на `reina`
из `/var/www/amanu`; копия его конфига лежит в `deploy/nginx/`.
Просмотры считает тот же first-party GoatCounter, что у сайта
подкаста и CTOdaily; дашборд доступен на `/goatcounter`.
