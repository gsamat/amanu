# Amanu 0.4.28

## Automatic recording

- Calls in Comet, the browser from Perplexity, now start automatic recording. Amanu recognises the browser and its helper processes, so Comet Helper is no longer reported as "not a call app". Existing custom application lists remain unchanged.

## Interface

- The Russian label for the auto-record switch now reads «Записывать встречи автоматически» in the menu, the status window and Settings.

## Compatibility

- Universal binary for Apple Silicon and Intel Macs running macOS 14.2 or later. Local transcription requires Apple Silicon; Intel requires a cloud transcription key and has not been tested on physical hardware.
