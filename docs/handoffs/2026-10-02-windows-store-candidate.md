# Amanu Windows Store candidate 0.6.3

Подписанный кандидат готов для передачи сессии, которая оформляет Microsoft Store. Он содержит исходное приложение Windows 0.6.3 и дополнительные подписи библиотек. Тихая установка и удаление проверены в чистом Windows профиле CI. Для подачи ещё нужен постоянный публичный HTTPS URL файла, который не изменяется после подачи.

- SHA256: `F258E7A03852B12BD605E14CD2F4D80337B06149B17880A8CDA938B29E981969`.

- [Пакет и отчёты подписи](https://github.com/gsamat/amanu/actions/runs/37025244784/artifacts/11234848216).
- [Отчёты проверки установки и цепочек подписи](https://github.com/gsamat/amanu/actions/runs/37026580893).

## Состав и подписи

Исходный payload взят из `windows-v0.6.3`, приложение имеет ProductVersion `0.6.3+10c41dff53a0e52cd821d37e9b2f190a87010972`. SHA256 исходного portable ZIP проверен: `965B9ECF2E555BED8975F55416CD9BE13433B193486D08E696A15164CFEFEF97`. Исходники приложения, модели и номер версии не менялись.

Полная инвентаризация нашла 508 PE файлов payload, включая DLL .NET, NAudio, Markdig, Velopack и оба native runtime. Azure Artifact Signing добавил подписи 34 ранее неподписанным DLL. Файлы с действительными встроенными подписями сохранены побайтно; это проверяется сравнением SHA256 до и после подписания. Установщик и созданные Velopack EXE подписаны Fands Software LLC. Использованы SHA256 и временные метки RFC3161 Microsoft.

В каждом упакованном portable ZIP и full nupkg проверено 510 PE файлов. Тихая установка фактически извлекла 510 подписанных PE файлов, которые также прошли проверку. Отдельный проход Windows SDK SignTool `verify /pa /all /v /tw` проверил встроенные подписи и доверенные цепочки 510 PE portable и установщика; все 511 проверок прошли, предупреждений о временных метках нет.

На подключённом Windows 11 компьютере отдельно проверены Authenticode подпись EXE и все 510 PE файлов каждого из распакованных ZIP и nupkg. Все имеют встроенные подписи, действительный статус Windows и временные метки. Отчёты: `local-installer-signatures.json`, `local-portable-signatures.json`, `local-nupkg-signatures.json` в указанной папке артефактов.

Рабочая установка пользователя и его записи не затрагивались. Native проверка установленной пользовательской Amanu.dll по WMI подтверждает прежнюю версию 0.6.3.0.

## Передача и публикация

Ветка подготовки: `codex/store-candidate-0.6.3`; рабочая копия: `C:\Users\samat\.codex\worktrees\store-candidate\amanu`. Итоговый workflow сохранён отдельно как `.github/workflows/windows-store-candidate.yml`; стабильный workflow восстановлен без изменений. Скрипты `Get-PeSignatureInventory.ps1` и `Test-StoreCandidateInstall.ps1` сохраняют полные отчёты. Последний намеренно разрешает установку только на одноразовом Windows runner, чтобы случайный запуск не изменил профиль пользователя.

Новый стабильный релиз не опубликован. Assets `windows-v0.6.3` и update feed сохранены: прежний Setup имеет SHA256 `E3D73CEF4D9EEE286C0DBEC7C34CB122BB72480F747FDBFFA72F0C493C89B3A4`, а portable ZIP — исходную сумму выше. Новый номер версии не нужен, поскольку изменения касаются подписей и упаковки, а код приложения совпадает с уже выпущенным 0.6.3.

Следующие действия публикующей сессии: загрузить неизменяемый установщик, проверить публичный URL без авторизации и SHA256, указать `--silent` в карточке Store, затем завершить подачу и дождаться проверки Microsoft. Это соответствует [требованиям Microsoft к EXE и MSI](https://learn.microsoft.com/en-us/windows/apps/publish/publish-your-app/msi/app-package-requirements).
