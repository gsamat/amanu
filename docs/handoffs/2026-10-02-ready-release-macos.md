# Выпуск Amanu 0.6.3 для macOS

Пользователь попросил заменить статус ожидания записи «не записывает» / `idle`
на «готов» / `ready`, выпустить Windows и macOS и синхронизировать их версии.
Общий следующий номер — **0.6.3**: ранее опубликованы macOS 0.6.1 и Windows 0.6.2.
Этот документ передаёт сессии на Mac оставшуюся работу по подписанному релизу macOS.
Публикация обеих платформ уже разрешена пользователем.

## Исходники для Mac

Репозиторий: <https://github.com/gsamat/amanu>.
Ветка для macOS: `codex/macos-ready-0.6.3`, основана на актуальном `master`.
[PR 27](https://github.com/gsamat/amanu/pull/27) содержит изменение статуса,
общий файл `VERSION`, обновление сборки и release notes.

Изменены подписи при создании и обновлении окна состояния
(`Sources/amanu/UI/StatusWindow.swift`) и меню
(`Sources/amanu/UI/MenuBarController.swift`). Внутреннее состояние `.idle`
сохранено. Новые подписи намеренно строчные, как остальные статусы интерфейса.
Существующий тест локализации обновлён для `ready` / «готов».

Дополнительное указание пользователя: «Расшифровка на ходу» заменена на
«Расшифровка на лету», включая подпись модели в SetupProgress.
Окончательный кодовый SHA macOS — `47c5de5`; последующие изменения документации
не меняют код. Windows-публикация остаётся у сессии Windows.

Номер версии теперь хранится в корневом `VERSION`, содержащем `0.6.3`.
`Makefile` и `scripts/release.sh` читают этот файл; не возвращайте отдельный
номер в `Makefile`. Release notes: `docs/release-notes-v0.6.3.md`.

## Проверки и публикация на Mac

1. Проверьте доступность Mac, чистоту рабочего дерева и текущую ветку.
   Не перезаписывайте чужие локальные изменения. Получите свежие ветки через
   `git fetch origin` и откройте ветку `codex/macos-ready-0.6.3` либо отдельный
   worktree из неё. Прочитайте действующий `AGENTS.md`.
2. Дождитесь зелёного CI в PR 27. CI запускает LocalVQE, Swift-тесты без
   параллельного выполнения, универсальную сборку, проверки сайта и
   release-скрипта. При сбое исправьте причину до публикации.
3. Проверьте реальный интерфейс macOS в русском и английском вариантах:
   окно состояния и меню показывают «готов» / `ready` до записи и после
   остановки. Во время записи и паузы соответствующие подписи сохраняются.
4. После успешной проверки влейте PR 27 в `master`, обновите локальный
   `master` и убедитесь, что `VERSION` равен `0.6.3`.
5. Запустите стандартный `scripts/release.sh` из чистого `master`.
   Скрипт сам выполняет проверки, универсальную сборку, Developer ID подпись,
   notarization, stapling, Sparkle подпись, публикацию GitHub и развёртывание
   canonical и legacy appcast. Прочитайте скрипт перед запуском.
6. Проверьте публичный релиз `v0.6.3`, доступность DMG и SHA-256, версию
   в `https://amanu.me/appcast.xml` и идентичность legacy feed
   `https://samat.me/amanu/appcast.xml`. Убедитесь, что английская и русская
   страницы сайта ведут на новый DMG. Установленные копии должны видеть
   обновление через Sparkle.

На Mac ожидаются существующие локальные средства подписи и публикации:
Sparkle private key, `.env.asc`, App Store Connect private key,
Developer ID certificate, авторизованный `gh`, SSH-алиас `reina` и checkout
legacy сайта. Их нет на Windows и в GitHub secrets для macOS.
Не выводите содержимое ключей и `.env.asc` в сообщения или логи.

## Работа на Windows

Windows-ветка: `codex/ready-0.6.3`. В неё уже подтянут актуальный `master`;
изменения macOS и Windows находятся вместе. Реализация Windows пока живёт
в отдельной ветке, как и предыдущие Windows-релизы. Не вливайте всю её
историю в `master` ради этого небольшого macOS-релиза.

Windows-проект, локальный release-скрипт и workflow читают тот же `VERSION`.
Windows-скрипт и workflow отклоняют явный номер, не совпадающий с файлом.
Windows сохраняет тег `windows-v0.6.3` и отдельный stable Velopack feed.

На доступном Windows 11 Pro 25H2, build 26200, выполнены:

- Release-сборка решения: 0 предупреждений, 0 ошибок.
- Core-тесты: 138 прошли, включая `ready` / «готов».
- Windows live-тесты: 28 прошли.
- Проверки безопасности workflow: 2 прошли.

[Подписанная Windows-сборка](https://github.com/gsamat/amanu/actions/runs/36996618441)
успешно завершилась из `10c41df` с номером 0.6.3. Windows-сессия повторно
проверила подписи Setup, приложения, updater и компонентов внутри update package
и portable ZIP на Windows; все подписи Fands Software LLC действительны,
с timestamp. Версия подписанного DLL — 0.6.3.0; SHA-1, SHA-256 и размер пакета
совпали с update feed. GUI проверен в обоих языках: `ready`, «готов» и
«Расшифровка на лету» отображаются правильно.

[Windows 0.6.3 опубликован](https://github.com/gsamat/amanu/releases/tag/windows-v0.6.3).
Публичные feed и SHA256SUMS совпадают с проверенными локальными файлами.
Коммит `bd64dbdd8efd71619c09c7bebb94c13e29bdfd24` в Windows-ветке содержит
обновлённые Windows-ссылки сайта EN/RU, общую документацию, Scoop manifest и
подготовленные WinGet manifests 0.6.3. Проверки сайта и `winget validate` прошли.
Mac-сессия может забрать этот коммит для единственного общего деплоя сайта.
WinGet manifests 0.6.3 пока не отправлены в каталог Microsoft; существующий
PR 445053 относится к 0.6.1 и ожидает review. Установка через новый WinGet
manifest в отдельном Windows-профиле не проверена: этот процесс не elevated.
