# Область независимого аудита Claude Code

Проверено состояние репозитория на 2026-09-06: HEAD b5e8a77, версия 0.4.15.

Три отдельных процесса локального Claude Code, модель claude-opus-5, effort=max:

1. recording: запись, автоматический старт/стоп, аудиомаршруты, live, транскрипция, восстановление, claims, naming и summary.
2. analytics-install: клиент аналитики, opt-out, очередь, установка, setup, настройки, разрешения, login item и обновления.
3. release-tests: сборка, релиз, CI, упаковка, сайт, сервер аналитики, тесты и готовность запуска.

Аудит запускался в safe-mode, с Read/Glob/Grep/Bash, без Edit/Write, MCP и сессий с автосохранением. Задание запрещало изменения проекта/настроек, чтение секретов/записей, deploy, публикации и обращения к production. Полные входные задания и stream-json находятся в игнорируемом .build/audit-2026-09-06/.

Ограничение атрибуции: отсутствие Co-Authored-By не доказывает авторство Codex. Код аналитики в e3d900b частично перенесён из Claude-атрибутированной ветки 7c6cb92. Для находок различаются появление в master, известное более раннее происхождение и неустановленный автор агента. Это не полная реконструкция всех приватных диалогов с агентами.

Результаты тестов и дополнительные воспроизведения выполнены Codex отдельно от Claude. Основные независимые отчёты сохранены без правок; сводка отдельно отмечает подтверждение и разногласия.
