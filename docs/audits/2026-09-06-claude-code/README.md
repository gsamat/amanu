## Что из Claude-отчётов не принимать буквально

1. **«В бандле нет лицензий bsdiff/sais» — опровергнуто.** Они присутствуют в поставляемом `Contents/Resources/Licenses/Sparkle-LICENSE`, строки 31–85. Makefile копирует весь файл с external notices. Изменения упаковки по этой находке не нужны.
2. **«Вызывать settle при выключенной транскрипции» — опасный совет.** При default keep_audio=false он удалит единственную копию встречи. Для режима только записи допустимо сжатие, а не потеря аудио.
3. **«Вернуть потолок подавления после manual stop» — не установленный баг.** Поведение намеренно закреплено `0e71efa` и тестом. Можно обсуждать UX и сигнал конца звонка, но нельзя снова запускать запись против ручной остановки просто по таймеру.
4. **«Добавить EchoFilter в mixed» недостаточно.** Когда неверно определена сторона говорящего, фильтру нечем восстановить правильную атрибуцию; смешанная расшифровка не даёт пару независимых дубликатов. Риск OpenAI+колонки обозначен самим проектом; нужен audio-based regression test и проверка алгоритма attribution.
5. **Некоторые P3 — лишь гипотезы.** Например, int16 overflow сейчас не достигается float32-тапами, порча JSON-пакета не показана, deadlock NSWorkspace.launch не воспроизведён. Они не объявлены здесь подтверждёнными launch blockers.
6. **Оценки приоритета не равны доказательствам.** P0 для отказа микрофона, P1 для отсутствующего Gotchas и P1 для обычной стартовой тишины завышены. Для реального удаления речи при echo-классификации приоритет, напротив, повышен.

Основные недостающие проверки — не ещё один assert на строку исходника, а переходы состояний: decode failure после prepare; неоднозначная echo-метка; off из другого процесса; смена/переполнение очереди во время send; CLI backpressure и timeout; denied permission после закрытия setup; чистый checkout без .build; HTTP-маршруты nginx.

До широкой раздачи нужен ручной проход на подписанном приложении: DMG → установка → deny/re-grant → звонок через колонки/гарнитуру → смена устройства → остановка → проверка обоих голосов в транскрипте; отдельно login item после logout/login. Физический Intel, реальные серверы моделей и production analytics не проверялись.

Аудит не гарантирует отсутствие других дефектов. Исходники приложения и три существовавшие незакоммиченные правки не изменены; добавлены только отчёты и диагностические примеры. Исправления, публикация и коммиты не выполнялись.
