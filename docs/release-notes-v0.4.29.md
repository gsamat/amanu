# Amanu 0.4.29

## Manage recordings

- Import and Open recordings folder are now at the top of the window. Actions for the selected recording, including Re-transcribe, are grouped below its details.
- Summary, Transcript and Speakers have separate tabs. Summaries and transcripts display Markdown headings, lists, emphasis and links, and their text can be selected and copied.
- The divider between the recording list and details can be moved to give either pane more room.
- Long opening excerpts in Speakers no longer force the window wider or prevent it from being reduced.
- Switching between meetings keeps the Speakers content anchored inside the tab instead of gradually moving it to the right and down.

## Validation and compatibility

- Checked switching between meetings, resizing and the formatted previews in the macOS app. This release changes the recordings interface; no audio capture changes are included.
- Universal binary for Apple Silicon and Intel Macs running macOS 14.2 or later. Local transcription requires Apple Silicon; Intel requires a cloud transcription key and has not been tested on physical hardware.
